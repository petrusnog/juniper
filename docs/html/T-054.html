T-054 — Embeddings locais

Para achar uma memória por significado ("framework PHP" acha "Laravel"), cada texto vira uma lista de números (um vetor). Isso roda na sua máquina, em CPU: o texto das memórias não sai daqui. Arquivos: brain/memory/embeddings.py e brain/memory/reindex.py. Decisões de fundo no ADR-011.

1. Como funciona

PeçaO que faz
EmbeddingProviderA interface: embed, embed_batch, dimension e model_id. O resto da memória só conhece ela, então dá para trocar por uma API externa depois.
LocalEmbeddingProviderRoda o multilingual-e5-small (ONNX) em CPU. O modelo (~120 MB) é baixado na primeira vez que for preciso para ~/.juniper/models e carregado sob demanda: quem não usa a memória nunca paga o custo.
Vetores384 números, de tamanho 1 (normalizados), então a similaridade por cosseno da T-055 é só um produto escalar.
kindpassage para o que é guardado, query para o que é buscado. O modelo foi treinado com esses prefixos; sem eles a busca piora.
juniper memory reindexRefaz os vetores das memórias cujo embedding_model não é o configurado (--force refaz todas).

2. Configuração

memory:
  embeddings:
    model: intfloat/multilingual-e5-small
    dir: ~/.juniper/models
    max_length: 512     # tokens por texto; o resto é cortado
    batch_size: 16

Trocar de modelo exige reindexar. Vetores de modelos diferentes não são comparáveis. Depois de mudar model, rode juniper memory reindex (precisa do MongoDB no ar). Dá para rodar de novo sem medo: cada memória só é marcada com o modelo novo depois de o vetor novo ser salvo, então uma execução interrompida continua de onde parou.

3. Erros

Sem rede na primeira vez, arquivo do modelo corrompido ou dependência faltando: a Juniper mostra uma mensagem em português dizendo o que fazer (EmbeddingUnavailableError), sem stacktrace. Um download cortado nunca fica com cara de completo (grava em .part e só então renomeia).

4. Limitações conhecidas

Ainda não há memórias. Esta task entrega só o gerador de vetores; o armazenamento e a busca vêm na T-055, a extração na T-056.

Latência e qualidade em PT-BR não foram medidas na VPS. O teste com o modelo real (pytest -m integration) baixa os ~120 MB e confere a busca por significado; os números de latência ficam para o PR/T-055.

Reindexar carrega as memórias na RAM de uma vez, o que é de sobra para o volume pessoal previsto (centenas a poucos milhares).

5. Como testar

pytest -m "not integration"   # CI: usa um modelo falso, sem rede
pytest -m integration         # baixa o modelo real
