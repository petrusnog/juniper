Configuração pronta

Onde ficam config.yaml e .env, a precedência e a referência de todas as opções.

Visão geral

A configuração tem um só ponto de acesso: from brain.config import settings (brain/config.py, pydantic-settings). Nenhum outro módulo lê variável de ambiente, YAML ou .env diretamente (ADR-003).

  • config.yaml guarda preferências (modelos, limites, agendas). Copie de config.yaml.example.
  • .env guarda segredos (chaves de API, usuário e senha do banco). Nunca é versionado e fica com permissão 600.

Precedência

Do que vence para o que perde:

  1. Argumentos do construtor (Settings(...))
  2. Variáveis de ambiente (JUNIPER_*)
  3. .env (~/.juniper/.env, depois ./.env)
  4. config.yaml
  5. Padrões do código

O config.yaml é procurado em: JUNIPER_CONFIG_PATH → ~/.juniper/config.yaml → ./config.yaml. Se você já tinha um config.yaml, o valor dele vence o padrão do código (útil lembrar ao atualizar llm.priority).

Variáveis de ambiente

Prefixo JUNIPER_, aninhamento com __: JUNIPER_LLM__OLLAMA__URL vale llm.ollama.url.

VariávelO que é
JUNIPER_DEEPINFRA_API_KEYChave da DeepInfra (deepinfra.com/dash/api_keys).
JUNIPER_TELEGRAM_BOT_TOKENToken do bot do Telegram (o @BotFather entrega). Só o bot usa; é um segredo, nunca vai para código, imagem, log nem PR (Telegram).
JUNIPER_GROQ_API_KEYChave da Groq (console.groq.com/keys).
JUNIPER_MEMORY__MONGO__USERNAMEUsuário do MongoDB (lido também pelo docker-compose.yml).
JUNIPER_MEMORY__MONGO__PASSWORDSenha do MongoDB.
JUNIPER_CONFIG_PATHCaminho do config.yaml.
JUNIPER_AGENT__SHOW_TIMINGAtalho de agent.show_timing.

settings.paths.{home,logs,config} são calculados, não configuráveis.

telegram

O bot do Telegram (Telegram, ADR-016). O token fica em JUNIPER_TELEGRAM_BOT_TOKEN, não aqui.

OpçãoPadrãoO que faz
telegram.rate_limit_per_minute20Mensagens por minuto por usuário (de 1 a 600). Acima disso o bot avisa uma vez por janela e não chama o cérebro: um erro de loop não vira conta de LLM.
telegram.delete_after_hours0Apagar a mensagem do usuário e a resposta do bot depois de N horas (de 0 a 48). 0 desliga. O Telegram só deixa o bot apagar mensagens com menos de 48 h, então o prazo efetivo é limitado a 47,5 h. O agendamento fica em memória: se o bot reiniciar, o que estava marcado não é apagado.
telegram.allowed_user_ids[]IDs numéricos do Telegram de quem pode falar com o bot. Lista vazia = ninguém (nunca "todos"). Pelo ambiente: JUNIPER_TELEGRAM__ALLOWED_USER_IDS=[123456789].

Como adicionar uma opção

  1. Crie ou altere o submodelo pydantic em brain/config.py.
  2. Atualize o config.yaml.example.
  3. Adicione o teste em tests/test_config.py e a opção nesta página (um teste confere que toda opção das settings aparece aqui).
