Voz da Juniper

Desde o juniper install, tudo que a Juniper diz no terminal segue o mesmo padrão. Você sempre sabe quem está falando, venha a frase de uma IA ou de um texto fixo.

1. O padrão

🌿 JUNIPER: Olá, sou Juniper, sua assistente de automações favorita!
👤 VOCÊ: oi, tudo bem?
🌿 JUNIPER: Tô bem, e você? Como foi o dia?
PrefixoQuemObservação
🌿 JUNIPER:A JuniperSempre, em qualquer comando.
👤 VOCÊ:Você, ao digitarQuando a memória existir (Sprint 3), vira o seu nome. A troca é em um único ponto.

2. Fala gerada × fala fixa

Nem tudo precisa de IA. Comandos que sempre dizem a mesma coisa usam texto pronto: é instantâneo, grátis e funciona sem internet. Só o chat chama o LLM.

TipoOndeComo fala
Gerada (IA)juniperO LLM escreve a resposta; o terminal coloca o prefixo e mostra token a token.
Fixajuniper (sem argumentos)Apresentação e lista de comandos.

ConfirmaçõesNa conversa: "Posso apagar esses cinco? É irreversível." e você responde "sim". Sem [y/N].
Perguntas dos scriptsEla pergunta; a resposta é sua, com o seu prefixo.
ErrosEm português, com o que fazer.
Abertura e despedida do chat"Pode falar, tô te ouvindo" e "Até logo!".

Regra para comandos novos: se a resposta é sempre a mesma, escreva um texto fixo e fale por _juniper_say (shell) ou voice.say (Python). Só use o LLM quando a resposta depender do que você disse.

3. Como é implementado

Shell (zsh)

_juniper_say "mensagem"
_juniper_ask "pergunta?" resposta

shell/core/voice.sh. _juniper_ask mostra a pergunta com o prefixo dela e lê a sua resposta com o seu prefixo.

Python

from brain.clients import voice

voice.say(console, "mensagem")
voice.user_prompt()   # "👤 VOCÊ: "

brain/clients/voice.py. Os instaladores em bash têm as mesmas duas constantes.

Um teste (test_shell_and_python_voices_are_identical) garante que os prefixos do shell, do Python e dos instaladores são exatamente os mesmos.

4. Detalhes do chat

Prefixo só quando há texto. Se o LLM falha antes de escrever, não sobra uma linha "🌿 JUNIPER:" vazia: o erro vem como fala dela.

Eco do nome é removido. Se o modelo começar a frase com "Juniper:" ou "🌿 JUNIPER:", o terminal descarta, para não aparecer duplicado.

Confirmação é diálogo. Ela pergunta em palavras, você responde "sim" ou "não", e ela conta o resultado. Funciona igual por voz.

Texto puro. A fala nunca é interpretada como markup: colchetes e asteriscos aparecem como foram escritos.

5. Fora do padrão (de propósito)

Scripts de desenvolvimento (scripts/try_*.py, healthcheck.py, check_google.py) e a saída crua de ferramentas (a lista de commits do search, a ajuda do --help do Typer) não são fala dela e ficam como estão.
