Guia de instalação

Como instalar a Juniper e todas as dependências de desenvolvimento, a partir de uma máquina limpa. Não precisa ter Python instalado e nada é instalado no sistema: tudo fica dentro de ~/.juniper, num ambiente virtual.

1. Instalação rápida

Você precisa só de git, bash e curl (ou wget).

git clone git@github.com:petrusnog/juniper.git ~/.juniper
bash ~/.juniper/scripts/install.sh

No final aparece "Juniper instalada e pronta para uso". Abra um terminal novo e rode:

juniper

Depois da primeira instalação o comando também existe dentro do shell: juniper install faz o mesmo (veja a seção 4).

Durante a instalação ela pede só uma coisa que não tem como descobrir sozinha: as chaves dos LLMs: DeepInfra, o cérebro principal (deepinfra.com/dash/api_keys), e Groq, o plano B grátis (console.groq.com/keys). Cole e pronto; Enter pula, e você pode colocar depois em ~/.juniper/.env.

Python: sem Python na máquina

O instalador procura um Python 3.11+ que consiga criar ambientes virtuais. Se achar, usa. Se não achar (ou se for um Python incompleto, como o do Ubuntu sem python3-venv), baixa o uv com verificação de checksum e usa-o para baixar um Python 3.12 isolado. Os dois ficam em ~/.juniper/.tools/, sem root e sem tocar no que já existe.

Rodar o instalador de novo é seguro: numa instalação saudável ele só confirma ("nada a fazer") em poucos segundos.

Falhas de rede

Cada download e instalação é tentado até 3 vezes. Se mesmo assim falhar, a mensagem diz a causa em português (por exemplo, "sem conexão com a internet") e o detalhe técnico fica em ~/.juniper/logs/install.log. O instalador só termina com sucesso se o teste final passar.

Desenvolvimento (--dev)

A fonte de verdade é o pyproject.toml.

Ferramentas do sistema (o instalador só avisa, não consegue instalar sem root): git e zsh para os comandos search/deploy. O Ollama é opcional (plano B se a Groq falhar).

4. Opções

OpçãoEfeito
--devInstala também pytest, pytest-asyncio, ruff e mypy.
--checkSó verifica e diz se está saudável; não altera nada.
--cleanApaga o ambiente e instala do zero.
--yesSem perguntas (scripts e CI).
--no-rcNão altera ~/.zshrc nem ~/.bashrc.
juniper install --dev          # dentro do shell (zsh), ou:
juniper install --check        # pelo binário Python
bash ~/.juniper/scripts/install.sh --dev

5. Ambiente de desenvolvimento

bash ~/.juniper/scripts/install.sh --dev
source ~/.juniper/.venv/bin/activate

pytest tests/ -v          # testes (não usam rede nem chave real)
ruff check brain/ tests/  # lint
mypy brain/               # tipos (strict)

Uma task só está pronta quando os três passam (Definition of Done em docs/JUNIPER.md).

Sem o instalador (manual)

python3 -m venv ~/.juniper/.venv
~/.juniper/.venv/bin/pip install -e "~/.juniper[dev]"
cp ~/.juniper/config.yaml.example ~/.juniper/config.yaml
cp ~/.juniper/.env.example ~/.juniper/.env      # preencha JUNIPER_GROQ_API_KEY

6. O que é alterado na sua máquina

OndeO quê
~/.juniper/.venv/Ambiente virtual com as dependências.
~/.juniper/.tools/uv e Python isolado (só se não havia Python utilizável).
~/.juniper/config.yaml, .envConfiguração (o .env fica com permissão 600).
~/.local/bin/juniperAtalho para o executável.
~/.zshrcLinha que carrega os comandos do shell (search, deploy...). Troca a linha antiga ~/.juniper/juniper.sh pela nova.
~/.zshrc, ~/.bashrcInclui ~/.local/bin no PATH, se ainda não estiver.
~/.juniper/logs/Log da instalação e os logs de uso.

Antes de alterar um arquivo de shell, o instalador guarda uma cópia ao lado dele (.zshrc.juniper.bak). Para desfazer tudo: bash ~/.juniper/scripts/uninstall.sh.

7. Opcionais

Ollama (reserva local, o último da fila). Instale em ollama.com e rode ollama pull llama3.1. A Juniper usa quando a DeepInfra e a Groq falham.

Agenda do Google. Precisa de conta de serviço e agenda própria; o passo a passo está na página T-022. Valide com python scripts/check_google.py.
