Painel de status

Até onde a Juniper está funcional hoje. Esta página mostra o resultado da última execução de scripts/healthcheck.py; ela não roda nada sozinha (um HTML não pode chamar Python).

1. Rodar a verificação

python scripts/healthcheck.py

Roda os testes automatizados, chama o Ollama (e a Groq, se houver chave) de verdade e atualiza esta página. Depois, recarregue-a (F5).

python scripts/healthcheck.py --no-live

Versão offline: só testes, sem chamar modelos (rápida).

python scripts/healthcheck.py --full

Inclui também o mypy --strict.

Experimente na mão

Conversar com o Ollama 
python scripts/try_ollama.py

REPL com a persona. Sem ferramentas e sem memória entre execuções.

Suíte de testes completa 
pytest tests -v

Tudo com servidores e SDKs falsos: não precisa de rede.

CLI atual 
juniper version

Mostra a versão e confirma que o comando está instalado. Para conversar: juniper (veja o CLI).
