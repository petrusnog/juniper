Features

As marcadas como "pronta" têm página. As demais aparecem quando forem implementadas.

Como adicionar uma página nova

1. Copie T-011.html como base (mantenha o <link> do CSS, <main id="content"> e o <script> do layout.js).

2. Em assets/layout.js, na lista FEATURES, preencha file e troque status para "done". A barra lateral e os cards do índice se atualizam sozinhos.
