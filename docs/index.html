1. Instalação

  1. Tenha Python 3.11+ e git instalados.
  2. Clone o repositório: 
    git clone git@github.com:petrusnog/juniper.git ~/.juniper
cd ~/.juniper
  3. Gere antes a chave da conta de serviço (veja a seção 2) e anote onde o arquivo .json foi salvo.
  4. Rode o instalador: 
    ./scripts/install.sh

O instalador cria o venv, instala as dependências, gera config.yaml e .env e o link global juniper. Além disso, ele:

  • cria a pasta ~/.juniper/certs/ (permissão 700);
  • pergunta o caminho da sua chave de conta de serviço — o arquivo pode ter qualquer nome (ex.: ~/Downloads/meu-projeto-a1b2c3.json);
  • valida o JSON e o copia para ~/.juniper/certs/gcp-key.json (permissão 600).
Caminho da chave de conta de serviço do GCP (enter para pular): ~/Downloads/meu-projeto-a1b2c3.json
[ OK ] Chave copiada para /home/voce/.juniper/certs/gcp-key.json

Opções do instalador

  • --gcp-key=/caminho/chave.json — informa a chave sem prompt (útil em automações).
  • --clean — recria o venv do zero.
  • --no-ollama — pula a validação do Ollama.
  • --ci — modo não interativo (a chave do GCP é pulada se não for informada).
Pulou a chave sem querer? Rode ./scripts/install.sh --gcp-key=CAMINHO a qualquer momento — o instalador é idempotente.

2. Conta de serviço no GCP

A Juniper usa uma conta de serviço do Google Cloud para se autenticar. Passo a passo no console:

2.1 Projeto

  1. Acesse console.cloud.google.com e entre com sua conta Google.
  2. No seletor de projetos (topo da página), escolha um projeto existente ou clique em Novo projeto, dê um nome e crie.
  3. Confirme que o projeto está ativo no seletor antes de continuar.

2.2 Ativar as APIs necessárias

  1. Menu ☰ → APIs e serviços → Biblioteca.
  2. Pesquise cada API que a Juniper vai usar e clique em Ativar.

2.3 Criar a conta de serviço

  1. Menu ☰ → IAM e administrador → Contas de serviço.
  2. Clique em + Criar conta de serviço.
  3. Informe um nome (ex.: juniper) e uma descrição; clique em Criar e continuar.
  4. Em Conceder acesso a este projeto, escolha o papel mínimo necessário (princípio do menor privilégio). Evite Proprietário/Editor.
  5. Clique em Concluir (o terceiro passo, de acesso de usuários, é opcional).

2.4 Gerar a chave JSON

  1. Na lista de contas de serviço, clique no e-mail da conta criada.
  2. Aba Chaves → Adicionar chave → Criar nova chave.
  3. Selecione o tipo JSON e clique em Criar.
  4. O navegador baixa um arquivo como meu-projeto-a1b2c3d4e5f6.json. Esse é o único momento em que a chave é exibida — guarde o arquivo.
  5. Anote o caminho do arquivo e informe-o quando o instalador perguntar. O nome pode ser qualquer um: a Juniper o copia para certs/gcp-key.json.
Segurança: a chave dá acesso ao seu projeto. Nunca a versione no git (a pasta certs/ já está no .gitignore), não a envie por chat/e-mail e apague o arquivo baixado depois da instalação. Se vazar, volte à aba Chaves e exclua-a imediatamente.

2.5 Conferir

ls -l ~/.juniper/certs/gcp-key.json    # deve mostrar -rw------- (600)

3. Comandos

  • juniper version — exibe a versão.
  • juniper docs — abre este livro de bolso em uma nova aba do navegador padrão.
  • juniper chat "mensagem" — conversa com a Juniper (em desenvolvimento).
  • juniper --help — lista todos os comandos.

4. Problemas comuns

  • "o JSON não é de uma conta de serviço" — você apontou para outro tipo de credencial (ex.: OAuth client). Gere uma chave JSON em Contas de serviço (seção 2.4).
  • "Arquivo não encontrado" — confira o caminho; ~ e arrastar o arquivo para o terminal funcionam.
  • juniper docs não abre o navegador — em servidores sem interface gráfica, o comando imprime o endereço file:// para você abrir manualmente.
  • Substituir a chave — rode o instalador de novo e responda s quando perguntar.
